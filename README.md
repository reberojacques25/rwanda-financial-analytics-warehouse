# Rwanda Financial Analytics Warehouse (RFAW)

A professional, reproducible data engineering and analytics project using verified public financial and economic data from Rwanda's authoritative sources.

## Project Purpose

Build a real data warehouse and analytics system using publicly accessible Rwanda financial data, with strict evidence-based methodology: no fabricated data, no interpolation, clear separation of observed vs. derived values, and full provenance tracking.

## Architecture

```
data/
  metadata/     → Source catalog, indicator dictionary (committed)
  raw/          → Downloaded source files (gitignored)
  interim/      → Intermediate processing files (gitignored)
  processed/    → Transformed analytical tables (gitignored, generated by pipeline)
sql/
  001_create_schemas.sql        → Database schema setup
  002_create_metadata_tables.sql → Metadata/provenance tables
  003_create_staging_tables.sql  → Raw data staging tables
  004_create_marts.sql           → Analytical mart tables
src/rfaw/
  config.py                     → Configuration and constants
  ingest/                       → Source-specific ingestion modules
  transform/                    → Data transformation modules
  warehouse/                    → Database connection and loading
  validation/                   → Data quality checks
  analysis/                     → Analytical scripts
dashboard/
  app.py                        → Streamlit dashboard
scripts/
  run_pipeline.py               → Full pipeline runner
  init_db.py                    → Database initialization
  run_validation.py             → Validation suite runner
tests/                          → Test suite
docs/                           → Documentation
```

## Setup

```bash
# Clone and install
git clone https://github.com/reberojacques25/rwanda-financial-analytics-warehouse.git
cd rwanda-financial-analytics-warehouse
pip install -r requirements.txt

# Copy environment config
cp .env.example .env
# Edit .env with your PostgreSQL credentials

# Initialize database (requires PostgreSQL running)
python scripts/init_db.py

# Run the data pipeline
python scripts/run_pipeline.py

# Run validation
python scripts/run_validation.py

# Run tests
pytest tests/ -v

# Launch dashboard
streamlit run dashboard/app.py
```

## Data Sources

| Source | Organization | Type | Format | Coverage |
|--------|-------------|------|--------|----------|
| Interest Rate Structure | BNR | VERIFIED_PRIMARY | XLS | 2002-2025 |
| World Development Indicators | World Bank | VERIFIED_SECONDARY | API | 2000-2024 |
| Financial Sector Statistics | BNR | VERIFIED_PRIMARY | PDF/Web | Multi-year |
| MPFSS Reports | BNR | VERIFIED_PRIMARY | PDF | 2019-2024 |
| Exchange Rates | BNR | VERIFIED_PRIMARY | Web | Daily |
| GDP National Accounts | NISR | VERIFIED_PRIMARY | PDF/Web | Multi-year |
| CPI/Inflation | BNR/NISR | VERIFIED_PRIMARY | PDF/Web | Monthly |
| Bank Disclosures (I&M, BK) | Listed banks | VERIFIED_PRIMARY | PDF | Per bank |

See `data/metadata/source_catalog.yml` for full provenance details.

## Evidence Classifications

- **VERIFIED_PRIMARY**: Directly from the primary source (BNR, NISR)
- **VERIFIED_SECONDARY**: From reputable international compilers (World Bank, IMF)
- **DERIVED**: Computed from observed values (e.g., annual averages from monthly)
- **ESTIMATED**: Model-based estimates (not used unless clearly labeled)
- **UNVERIFIED**: Source could not be verified (not used in analysis)

## Key Limitations

1. Banking-sector data is aggregate, not bank-by-bank for all licensed banks
2. PDF extraction required for BNR/NISR publications
3. No interpolation or fabrication of missing data
4. Macro variables are national constants — cannot explain cross-bank variation
5. World Bank/IMF data are secondary sources with possible estimates
